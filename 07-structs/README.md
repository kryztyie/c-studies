# Module: Structures in C

## 📝 Description
This module contains **10 exercises focused on `structures (struct)` in C**.  
It explores how to **group different data types, organize related information, and manipulate structured data using function and arrays of `struct`**, including:

- Declaring and initializing structs
- Accessing struct members 
- Passing structs to functions
- Arrays (vectors) of structs
- Updating struct data through functions
- Nested structures (struct inside another struct)
- Pratical applications using menus and `switch` statements

The exercises are designed to **strengthen logical thinking, data organization, and modular programming using `structs`**.

## 🧠 Key Exercises

- **Person Struct** – Defines a struct with name, age and height, and prints its data.  
- **Student Data Reader** – Reads and displays students information using a struct.  
- **Product Struct** – Uses a struct with name, price and quantity.  
- **Array of Structs** – Stores and processes multiple records using a vector of structs. 
- **Struct as Function Parameter** – A function receives a struct and prints its data.
- **Product Price Update** – Updates a product’s price through a function.  
- **Nested Struct (Address inside Person)** – Demonstrates struct nesting for complex data.  
- **Simple Contact List** – Implements a basic contact list using structs and strings..  
- **Cash Register System** – Simulates product registration, sales, and final report using structs.  
- **Simple Agenda** – Implements a menu-based contact agenda using structs.

> Each exercise emphasizes **data encapsulation**, **struct manipulation** and **real-world modeling using structures**.

## ▶️ How to Compile and Run

1. **Compile the C file** using GCC:

```bash
gcc exercise_name.c -o exercise_name
```
2. **Run the compiled program**

```bash
./exercise_name
```
Replace exercise_name with the actual filename of the exercise you want to run.

## ℹ️ Notes

- Each exercise is independent and can be compiled and executed separately.

- All data is handled in memory, no file handling is used.

- Structs are used to group related data and improve code organization.

- Modify input values to test different scenarios.

- Make sure to save your files with the .c extension.
