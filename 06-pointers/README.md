# Module: Pointers in C

## 📝 Description
This module contains **10 exercises focused on `pointers` in C**.  
It explores **memory addressing, pointer manipulation, and dynamic memory allocation**, including:

- Pointer declaration and dereferencing 
- Passing variables and arrays to functions using pointers 
- Modifying values through memory addresses
- Array manipulation using pointers
- Returning values via pointer-based logic
- Basic dynamic memory allocation with `malloc`

The exercises are designed to **strengthen understanding of memory, address manipulation, and low-level data handiling in C**.

## 🧠 Key Exercises

- **Swap Values Using Pointers** – Swaps two variable values using pointer parameters.  
- **Sum Two Numbers Using Pointers** – Adds two numbers by accessing them through pointers.  
- **Find the Largest Value** – Returns the largest of two values using pointers.  
- **Print Variable Addresses and Values** – Displays both memory addresses and stored values. 
- **Modify Array Using Pointers** – Changes array elements through pointer access.
- **Reverse Array Using Pointers** – Reverses an array using pointer arithmetic.  
- **Search Value in Array Using Pointers** – Searches for a value in an array using pointers.  
- **Basic Dynamic Memory Allocation** – Demonstrates simple use of `malloc`.  
- **Create and Fill Array with malloc** – Allocates memory dynamically and fills an array.  
- **Sum Array Elements Using Pointers** – Calculates the sum of array elements via pointers.

> Each exercise emphasizes **memory addressing**, **pointer arithmetic** and **safe manipulation of data through pointers**.

## ▶️ How to Compile and Run

1. **Compile the C file** using GCC:

```bash
gcc exercise_name.c -o exercise_name
```
2. **Run the compiled program**

```bash
./exercise_name
```
Replace exercise_name with the actual filename of the exercise you want to run.

## ℹ️ Notes

- Each exercise is independent and can be compiled and executed separately.

- Pointers are used explicitly to reinforce understanding of **memory access and data manipulation**

- Dynamic memory allocated with `malloc` should be handled carefully to avoid memory leaks.

- Modify input values to test different scenarios.

- Make sure to save your files with the .c extension.
