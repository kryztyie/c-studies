# Module: Conditionals in C

## 📝 Description
This module contains **10 exercises focused on `conditional statements` in C**.  
It explores **decision-making logic and conditional flow control**, including:

- `if`, `else if` and `else` statements
- Nested conditionals  
- Logical and relational operators 
- Decision-making with `switch` statements
- Input validation using conditionals

The exercises are designed to **strengthen logical thinking, decision-making skills, and control flow using conditionals**.

## 🧠 Key Exercises

- **BMI Checker** – Calculates BMI and classifies the result based on conditions.  
- **Age Classification** – Classifies a person based on age ranges.  
- **Biggest Number** – Compares values and determines the largest number.  
- **Calculator (Switch)** – Performs basic arithmetic operations using `switch`.  
- **Guess the Password** – Validates input until the correct password is entered.  
- **Leap Year** – Determines whether a year is a leap year.  
- **Menu (Switch)** –Implements a menu-based system using `switch`.  
- **Odd or Even** – Checks whether a number is odd or even.  
- **Positive, Negative or Zero** – Classifies a number based on its sign  
- **Test Score** – Evaluates a score and displays the corresponding result.

> Each exercise emphasizes **logical conditions**, **branching** and **program flow control using decision structures**.

## ▶️ How to Compile and Run

1. **Compile the C file** using GCC:

```bash
gcc exercise_name.c -o exercise_name
```
2. **Run the compiled program**

```bash
./exercise_name
```
Replace exercise_name with the actual filename of the exercise you want to run.

## ℹ️ Notes

- Each exercise is independent and can be compiled and executed separately.

- Conditional statements control the flow of the program execution.

- `switch` statements are used for menu-based and multi-option decisions.

- Modify input values to test different scenarios.

- Make sure to save your files with the .c extension.
