# Module: Loops in C

## 📝 Description
This module contains **10 exercises focused on `loops`  in C**.  
It explores **repetition structures and iterative logic**, including:

- `for`, `while` and `do-while` loops
- Counting and accumulation logic  
- Loop-based input validation 
- Numerical sequences and series
- Conditional termination of loops

The exercises are designed to **strengthen logical thinking, repetition control, and problem-solving using loops**.

## 🧠 Key Exercises

- **Biggest Number** – Reads multiple numbers and determines the largest value.  
- **Countdown (10 to 0)** – Prints a countdown using a loop.  
- **Counting Letters** – Counts the number of characters in a word or string.  
- **Even Numbers (0 to 100)** – Prints all even numbers between 0 and 100.  
- **Factorial Calculator** – Calculates the factorial of a number using loops.  
- **Fibonacci Sequence** – Generates the Fibonacci sequence up to a given limit.  
- **Guess the Password** – Repeats input until the correct password is entered.  
- **Multiplication Table** – Displays the multiplication table of a number.  
- **Sum from 1 to N** – Calculates the sum of numbers from 1 to N.  
- **Sun Until Stop** – Continuously sums numbers until a stop condition is met.

> Each exercise emphasizes **iteration**, **loop control** and **algorithmic thinking using repetition structures**.

## ▶️ How to Compile and Run

1. **Compile the C file** using GCC:

```bash
gcc exercise_name.c -o exercise_name
```
2. **Run the compiled program**

```bash
./exercise_name
```
Replace exercise_name with the actual filename of the exercise you want to run.

## ℹ️ Notes

- Each exercise is independent and can be compiled and executed separately.

- Loops are used to control repetition and continuous execution.

- Input validation and termination conditions are handled using loops.

- Modify input values to test different scenarios.

- Make sure to save your files with the .c extension.
